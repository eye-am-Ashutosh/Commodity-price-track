Save to GitHub

  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Give it a name, pick an expiration, and under Repository access choose Only select repositories → your repository.
  3. Under Permissions, add Contents and set it to Read and write.
  4. Click Generate token, copy it, and paste it below. It stays in this browser and is only sent to GitHub.
